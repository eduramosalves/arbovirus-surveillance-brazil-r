# Alternative result visualizations (selected)

The 3 alternative encodings that were chosen during the side-by-side
exploration. They complement the main figures (`figures/main/`) and are not
numbered in the manuscript. Generated by `pipelines/alt_results.R`.

| Alt file | Replaces / pairs with | What changed |
|----------|-----------------------|--------------|
| `trend01_slope_first_last.png` | `figures/main/Figure2_trend_analysis.png`, `outputs/descriptive/py_05_sens_slope.png` | Slope chart of first vs last year per state, MK-significant states highlighted and labeled |
| `trend03_sen_dotbar.png` | `outputs/descriptive/py_05_sens_slope.png`, `outputs/descriptive/py_04_mannkendall_tau.png` | Sorted dot-and-bar of Sen slopes coloured by MK direction/significance |
| `glm02_caterpillar_temp_irr.png` | `figures/glm/glm_fig5_forest_significant.png` | All 27 states sorted by IRR, faded if non-significant — shows the full per-state distribution rather than only the significant ones |

The former map views (`spat01_choropleth_facet`, `spat02_lisa_facet`) were retired: every map is
now drawn once, with the three diseases as symbols, by `pipelines/arbovirus_geospatial.R`
(`figures/main/Figure6_combined_map.png`, `figures/supplementary/FigureS2_lisa_trend.png`).

## Regenerate

```bash
Rscript pipelines/alt_results.R
```

Writes the 3 PNGs into this folder, `figures/alternatives/` (it was `alt_results/` until 2026-10-22).
