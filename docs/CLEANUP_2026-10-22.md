Nothing was deleted. Every file listed here still exists, at the new path. `git log --follow <new path>` shows its history.
Counts: 194 files moved (16 quarantined, 122 results, 53 manuscript, 3 other).

The one place that decides which result file goes to which sub-folder is the layout table at the top of `R/utils.R`
(`OUTPUT_LAYOUT`, `FIGURE_LAYOUT`, used through `out_file()` and `fig_file()`).

## Code that changed with the moves

- `R/utils.R`: layout table and `out_file()`, `fig_file()`, `out_dir()`; the caption-notes file is written under `outputs/figure_notes/`.
- `pipelines/*.R` (12 scripts): `file.path(OUTPUT_DIR, name)` became `out_file(name)` and `file.path(FIGURES_DIR, name)` became `fig_file(name)`; `adv_common.R` writes to `outputs/additional/`; `alt_results.R` writes to `figures/alternatives/`.
- `R/install_packages.R` writes `docs/R_SESSION_INFO.txt` and no longer installs `xml2` (it only served the removed `.pzfx` reader).
- `etl/build_db.R` no longer copies `graphpad_data/`; `pipelines/graphpad_pipeline.R` lost the never-called `.pzfx` reader and the "General Data" branch.
- `manuscript/build/*`: paths derived from the script location instead of this machine's; new result paths; new `export_figures.py`.
- `.gitignore`: Office lock files, `Thumbs.db`, `desktop.ini`, `*.tmp`, `__pycache__/`, and the manuscript build scratch folders.

## How it was checked

- A rerun of the unchanged pipeline reproduced all 158 result files byte for byte (the pipeline is deterministic).
- After the changes, `run_all.R --skip-etl` finished all stages and every result file was identical to its pre-change copy at its new path. The only differences were five path strings in the notes sheets of `source_data/Additional_Figures.xlsx` and `source_data/GLM_Figures.xlsx`.
- `etl/check_db.R`: all 9 hashes match. `numbers.csv`: 4,779 keys, all values identical (only the source column changed). The manuscript rebuilt from `manuscript/build/` has the same text, 34 data assertions pass, `audit.py` and the schema validator pass, 43 of 43 independent recomputations match.
